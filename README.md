# Boland Spitbraai — Website Concept

A responsive multi-page website concept built as an unofficial presentation for Boland Spitbraai.

## Pages
- `index.html` — Home
- `about.html` — Our Story
- `menus.html` — Menus & Packages
- `gallery.html` — Gallery
- `events.html` — Functions & Events
- `quote.html` — Request a Quote
- `contact.html` — Contact

Shared assets are in `assets/css/styles.css` and `assets/js/main.js`.

## Important before launch
- This is an unofficial concept, not a commissioned or approved site.
- Stock images are illustrative, not verified photos of Boland Spitbraai's own events.
- Menu directions are examples. Confirm actual dishes, portions, prices, service, travel area and availability with the owner.
- Verify official contact details, service claims, testimonials and social links before publishing as an official business site.
- The quote form currently validates fields and displays a local preview only. It does not send or store enquiries and does not confirm bookings.
- Before accepting real enquiries, connect an owner-approved form service/backend, configure spam protection and appropriate privacy messaging, and test delivery.
- Replace stock images with owner-approved photography where possible and ensure rights to use each image.

## Enable GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save. After publishing, GitHub will show the live site URL in the Pages section.

## Technology
Static HTML, CSS and vanilla JavaScript. No build step required. Google Fonts and Unsplash images load over the internet.
